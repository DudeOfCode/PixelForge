# PixelForge

A fast, fully offline photo editor for Android. PixelForge wraps a self-contained
HTML5 editing engine in a native Android shell, so every feature runs on-device
with no internet connection and nothing ever leaves the phone.

## Features

- Open images from storage (picker + drag/drop) and capture from the camera
- Advanced camera: front/rear switch, torch, pinch/slider zoom, rule-of-thirds
  grid, and a 3s / 10s self-timer
- Adjust: brightness, contrast, saturation, sharpen
- Filters: Original, Magic (auto-levels), Vivid, Gray, B&W, Sepia, Warm, Cool
- Crop with draggable handles on every edge (2 corners + midpoint per side)
- Rotate 90 / 180, flip horizontal / vertical
- Background removal (flood-fill from edges) + solid colour fill
- Export as JPEG / WebP / PNG with resize by dimensions or percentage, and a
  "max size in KB" target that keeps the highest quality that fits
- Saved images land in **Pictures/PixelForge** in the device gallery
- Undo / Reset, and Android back-button navigation

## Project layout

```
PixelForge/
  app/src/main/assets/index.html      <- the editing engine (offline)
  app/src/main/java/.../MainActivity.kt <- WebView host + camera/file/save bridges
  app/src/main/AndroidManifest.xml
  build.gradle, app/build.gradle, settings.gradle
  gradlew, gradlew.bat                <- one-step, self-bootstrapping build
```

## Build the APK

**Requirements:** JDK 17+, Android SDK (platform 34 + build-tools), and internet
for the first dependency download.

### Option A - Android Studio (easiest)
1. Open the `PixelForge` folder in Android Studio (Koala or newer).
2. Let it sync Gradle, then **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
3. Or click **Run** to install straight onto a connected device/emulator.

### Option B - Command line (one step)
```bash
cd PixelForge
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```
The debug APK is written to:
```
app/build/outputs/apk/debug/app-debug.apk
```
Install it with `adb install app/build/outputs/apk/debug/app-debug.apk`.

A **release** build (`./gradlew assembleRelease`) additionally needs a signing
keystore configured in `app/build.gradle`.

## Notes

- The camera uses the browser `getUserMedia` API. The app serves its assets over
  a secure `https://appassets.androidplatform.net` origin (via WebViewAssetLoader)
  so the camera is allowed to start; the runtime CAMERA permission is requested
  on first use.
- Downloads generated by the editor (blob URLs) are intercepted and written to
  the gallery through `MediaStore`, so "Compress & download" saves a real file.
